# Cafe Startups 後端時序圖

本文件對應目前 Go 後端的 API 與 `internal/domain.Game` 流程。時序圖使用 Mermaid，可在支援 Mermaid 的 Markdown 預覽器中查看。

## 1. 建立遊戲與 Period 0 初始設定

```mermaid
sequenceDiagram
    actor Player as 玩家
    participant API as HTTP API
    participant Store as gameStore
    participant Game as domain.Game

    Player->>API: POST /api/games
    API->>Game: NewGame(seed, playerIDs)
    Game-->>API: Period 0 / hypothesis
    API->>Game: LoadCatalog + SetCatalog
    API-->>Player: lobby state

    Player->>API: POST /api/games/{id}/start
    API->>Game: AddPlayer(bot) x3
    API->>Game: Start()
    Game-->>API: 可開始初始選擇
    API-->>Player: playing / Period 0

    Player->>API: POST /api/games/{id}/setup
    API->>Game: SetInitialCards(partnerID, starterShopID)
    Game-->>API: 儲存選擇、標記 initialCardsSelected
    API-->>Player: 更新選擇結果

    Player->>API: BEGIN_EXPERIMENT
    API->>Game: BeginExperiment()
    Game->>Game: 扣除創始店成本
    Game->>Game: Period 0 -> Period 1
    Game->>Game: Round 0 / deal 7 cards
    Game-->>API: PhaseExperiment
    API-->>Player: 第 1 期新手牌
```

## 2. 一個實驗回合

```mermaid
sequenceDiagram
    actor Player as 玩家
    participant API as commandHandler
    participant Game as domain.Game
    participant Bot as runBots

    Player->>API: SELECT_CARD(cardID)
    API->>Game: SelectCard(playerID, cardID)
    Game-->>API: selected[playerID] = card
    API->>Bot: runBots()
    Bot->>Game: SelectCard(botID, cardID)

    alt 玩家打出卡牌
        Player->>API: PLAY_SELECTED_CARD
        API->>Game: PlaySelectedCard(playerID)
        Game->>Game: pay()
        Game->>Game: applyCardEffects()
    else 玩家棄牌
        Player->>API: DISCARD_SELECTED_CARD
        API->>Game: DiscardSelectedCard(playerID)
        Game->>Game: +DiscardRefund
    end

    Player->>API: PASS_HAND
    API->>Game: PassHands()
    Game->>Game: 檢查所有玩家已行動
    Game->>Game: 手牌依期別方向傳遞
    Game->>Game: Round + 1
    Game-->>API: 新回合或 PhaseLearning
    API-->>Player: 最新 gameVersion / state
```

## 3. 期末市場抽取與正式結算

```mermaid
sequenceDiagram
    actor Player as 玩家
    participant API as commandHandler
    participant Game as domain.Game

    Note over Game: 6 個實驗回合完成，進入 PhaseLearning

    Game->>Game: 自動建立來客袋數量
    Player->>API: DRAW_MARKET
    API->>Game: DrawMarket()
    Game->>Game: 市場袋 [1,2,3,4] 依 seed 洗牌
    Game->>Game: 取玩家人數並由大到小排序
    Game-->>API: marketRanking
    API-->>Player: 顯示 1st～4th 顧客數

    Player->>API: RESOLVE_LEARNING
    API->>Game: ResolveLearning()
    Game->>Game: 確認 marketRanking 已抽取
    Game->>Game: SettleInterest()
    Game->>Game: 依 DemandBoard 抽出顧客種類
    Game->>Game: DistributeCustomers()
    Game->>Game: SettleRevenue()
    Game->>Game: recordCashFlow()

    alt Period 3
        Game->>Game: 計算最終分數
        Game-->>API: PhaseFinished
    else Period 1 或 Period 2
        Game->>Game: Period + 1 / PhaseHypothesis
        Game->>Game: 清除 marketRanking
        Game-->>API: 等待 KPI 選擇
    end
    API-->>Player: 結算結果
```

## 4. 下一期 KPI 與發牌

```mermaid
sequenceDiagram
    actor Player as 玩家
    participant API as commandHandler
    participant Game as domain.Game
    participant Bot as runBots

    Player->>API: SET_KPI([kpiA, kpiB])
    API->>Game: SetKPIs(playerID, kpiA, kpiB)
    Game->>Game: 驗證 9 選 2 且不可重複
    API->>Bot: setRandomBotKPIs()
    Bot->>Game: SetKPIs(botID, ...)

    API->>API: allKPIsSelected()
    alt 所有玩家已完成 KPI
        API->>Game: BeginExperiment()
        Game->>Game: Round = 0
        Game->>Game: 依目前 Period 篩選 Catalog
        Game->>Game: 每位玩家發 7 張牌
        API-->>Player: 新期手牌
    else 尚有玩家未完成
        API-->>Player: 等待其他玩家
    end
```

## 5. API 與 domain 對照

| API command | Domain method | 主要狀態變更 |
|---|---|---|
| `BEGIN_EXPERIMENT` | `BeginExperiment()` | 進入實驗、設定 Round 0、發牌 |
| `SET_KPI` | `SetKPIs()` | 儲存本期兩個計分指標 |
| `SELECT_CARD` | `SelectCard()` | 記錄玩家選牌 |
| `PLAY_SELECTED_CARD` | `PlaySelectedCard()` | 扣款、放入 Tableau、套用卡牌效果 |
| `DISCARD_SELECTED_CARD` | `DiscardSelectedCard()` | 棄牌並取得補貼 |
| `PASS_HAND` | `PassHands()` | 傳牌、增加 Round、進入 learning 時自動建立來客袋 |
| `DRAW_MARKET` | `DrawMarket()` | 抽取並保存市場排名顧客數 |
| `RESOLVE_LEARNING` | `ResolveLearning()` | 利息、顧客、營收、現金流與換期 |
| `TAKE_LOAN` | `TakeLoan()` | 增加貸款與現金 |

## 6. 重要狀態轉移

```text
Period 0 / hypothesis
  -> BEGIN_EXPERIMENT
Period 1 / experiment / round 0..6
  -> DRAW_MARKET
Period 1 / learning / marketRanking ready
  -> RESOLVE_LEARNING
Period 2 / hypothesis
  -> SET_KPI (all players)
Period 2 / experiment / round 0..6
  -> ...
Period 3 / learning
  -> RESOLVE_LEARNING
finished
```
